## Overview

This project builds a complete **Spam Detection pipeline** from scratch:

- Loads and cleans the **UCI SMS Spam Collection** dataset (5,572 messages)
- Preprocesses text through a 4-step NLP pipeline
- Converts text to numerical features using **TF-IDF** (5,000 features + bigrams)
- Trains a **Multinomial Naive Bayes** classifier achieving ~97.9% accuracy
- Saves model artefacts with **Pickle** for fast inference
- Serves real-time predictions through a **Flask REST API** with a dark-mode UI

## How It Works

Every message goes through this preprocessing pipeline before prediction:

```
Raw message  →  Lowercase  →  Remove symbols/numbers  →  Remove stopwords  →  Stem  →  TF-IDF  →  Predict
```

| Step | What happens | Example |
|---|---|---|
| **1. Lowercase** | Normalise all text | `"FREE PRIZE"` → `"free prize"` |
| **2. Remove non-alpha** | Strip numbers, punctuation, symbols | `"win £900!"` → `"win  "` |
| **3. Remove stopwords** | Drop common words with no signal | `"you have won"` → `"won"` |
| **4. Porter Stemming** | Reduce words to root form | `"winning"` → `"win"` |

After preprocessing, **TF-IDF** converts the cleaned text into a numerical matrix where rare, distinctive words like `"winner"` and `"prize"` score higher than common words. **Multinomial Naive Bayes** then uses Bayes' theorem to compute the probability of Spam vs Ham and returns the class with the higher score.

## Setup & Installation

### Prerequisites
- Python 3.9 or higher
- pip

---

### Step 1 — Clone the repository
```bash
git clone https://github.com/<your-username>/spam-classifier.git
cd spam-classifier
```

### Step 2 — Create a virtual environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### Step 3 — Install dependencies
```bash
pip install -r requirements.txt
```

### Step 4 — Download the dataset

This project uses the **UCI SMS Spam Collection Dataset**.
You can download `spam.csv` from any of these sources:

| Source | Link |
|---|---|
| Kaggle | https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset |
| UCI ML Repository | https://archive.ics.uci.edu/dataset/228/sms+spam+collection |
| GitHub (direct) | Search "SMS Spam Collection dataset spam.csv" on GitHub |

> **Note:** The file must be named `spam.csv` and placed in the
> project root folder (same level as `train_model.py`).
> The dataset should have two columns — a label column (`ham`/`spam`)
> and a message column — separated by a tab or comma.

## Running the Project

### Step 1 — Train the model
```bash
python train_model.py
```

This will:
- Perform EDA and save 3 visualisation plots to `static/`
- Preprocess all 5,572 messages
- Train and evaluate the Naive Bayes model
- Print accuracy, precision, recall, and F1-score
- Save `models/spam_model.pkl` and `models/tfidf_vectorizer.pkl`

---

### Step 2 — Start the Flask server
```bash
python app.py
```

---

### Step 3 — Open the app
Visit **http://127.0.0.1:5000** in your browser.

Type any message and click **Classify Message** to get an instant Spam / Ham prediction with confidence score.

## Model Performance

Evaluated on a held-out test set (20% of data, stratified split):

| Metric | Score |
|---|---|
| ✅ Accuracy | **97.58%** |
| 🎯 Precision | **96.21%** |
| 🔍 Recall | **85.23%** |
| ⚖️ F1-Score | **90.39%** |

> Results may vary slightly due to random train/test split seeding.

## API Endpoints

| Method | Route | Description |
|---|---|---|
| `GET` | `/` | Serves the web UI |
| `POST` | `/predict` | Classifies a message, returns JSON |
| `GET` | `/health` | Health check for deployment platforms |

### POST /predict

**Request body:**
```json
{
  "message": "You have won a £900 prize! Call now to claim."
}
```

**Response:**
```json
{
  "prediction": "Spam",
  "confidence": 97.3,
  "spam_prob": 97.3,
  "ham_prob": 2.7,
  "clean_text": "won prize call claim"
}
```
